# v1.1.0 - Compartment-Specific Rationale and Gate 0 Update

## Summary

This release updates the evidence-constrained mechanistic hypothesis from V1.6 to V1.7.1 by introducing an explicit renal miR-98-5p actionability Gate 0 and separating peripheral IgAN miR-98 biology from renal resident-cell biology.

## What changed since v1.0.0

- Adds a compartment-specific rationale for peripheral/systemic versus renal resident-cell miR-98-5p biology.
- Defines Gate 0A as auxiliary phenotype mapping, Gate 0B as the true functional go/no-go gate, and Gate 0C as exploratory LIN28/biogenesis work.
- Adds five targeted primary-literature records while keeping exact-disease peripheral and cross-disease renal/mesangial evidence separate.
- Corrects the BACH1 to NF-kappaB/p65 classification to direct functional human mesangial cross-context evidence.
- Separates family-level LIN28/let-7 processing evidence from LIN28 pri/pre-miR-98 processing evidence.
- Updates Figure 1 and explicit stop rules.

## What remains unresolved

- IgAN renal mature miR-98-5p localization and direction.
- A demonstrated desired renal miR-98-5p effect in an IgAN-relevant human context.
- Direct miR-98-5p regulation of TNFAIP3/A20 in relevant human renal cells.
- Functional need to preserve A20 under IgAN-relevant stimulation.
- Any selective target-site protector, its sequence, delivery, and effect.

## What this release does not claim

This release does not claim a confirmed mechanism, a validated target, an effective intervention, therapeutic efficacy, fibrosis reversal, clinical benefit, a validated target-site protector, or patient-level prediction.

## Files included

The bundle contains the V1.7.1 scientific master manuscript, V1.7.1 evidence/context materials, an author-generated conceptual figure, reference QA, provenance documentation, and integrity checksums. It excludes Frontiers administration files, cover letters, submission-system fields, internal blockers, historical scripts, downloaded publisher content, and raw patient datasets.

## Provenance note

Historical development-stage scripts are not presented as the verified code used to generate manuscript conclusions. This release contains no new wet-lab experimental dataset.
