# Release provenance

## Release identity

- Public release version: `v1.1.0`
- Release title: `Compartment-Specific Rationale and Gate 0 Update`
- Internal release identifier: `V1.7.1_PUBLIC_EVIDENCE_PACKAGE`
- Scientific source priority: V1.7.1 scientific master, then Frontiers formatting adaptation for consistency checking, then the historical V1.6 public package.

## Source selection

The manuscript in this release is the frozen V1.7.1 scientific master, copied without scientific editing. Its public Markdown representation was derived from that master. The public PDF was rendered from the same master. The high-resolution TIFF is retained from the final journal-format package solely as the high-resolution counterpart of the V1.7.1 author-generated gate architecture; its scientific content was checked against the V1.7.1 master figure.

## Public/private decision

Included material is limited to author-generated scientific synthesis, derived evidence records, author-generated conceptual figures, and reproducibility provenance. Excluded material includes Frontiers cover letters, submission metadata, copy/paste fields, scope forms, blockers, correspondence, screenshots, portal information, private workspaces, historical scripts, publisher PDFs/figures, and raw patient data.

## Historical code provenance

Historical development-stage scripts are not presented as code used to generate manuscript conclusions because their execution provenance has not been fully verified. They are not duplicated in this release.

## Integrity

`MANIFEST.md` and `SHA256SUMS.txt` provide release-file provenance and integrity checking. By standard convention, `SHA256SUMS.txt` does not include a checksum for itself; all other release files, including `MANIFEST.md`, are included in it.
